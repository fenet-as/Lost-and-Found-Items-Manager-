# Lost and Found Items Manager

A console-based Lost and Found Items Management System built with **C++** and file system storage (FS).

This project is designed to help manage lost and found items efficiently through a simple command-line interface. Users can add, search, update, and manage records of lost or found items while storing data locally using file handling techniques in C++.

---

## 🚀 Features

* ➕ Add lost or found items
* 🔍 Search for items
* 📋 View all stored records
* ✏️ Update existing item information
* ❌ Remove item records
* 💾 Persistent data storage using file handling
* 🖥️ Simple and user-friendly console interface


---


## 🎯 Project Purpose

The purpose of this project is to demonstrate:

* Practical use of C++ programming
* File handling and persistent storage
* Data organization and management
* Problem-solving using real-world scenarios

This system simulates how institutions, campuses, or organizations can digitally manage lost and found items instead of relying on manual records.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/fenet-as/Lost-and-Found-Items-Manager.git
```

### 2. Navigate to the project directory

```bash
cd Lost-and-Found-Items-Manager
```

### 3. Compile the program

Using g++:

```bash
g++ main.cpp -o lostfound
```

### 4. Run the application

```bash
./lostfound
```

For Windows:

```bash
lostfound.exe
```
